Логи с iPhone в два тапа

Один раз собери быструю команду. После этого в Telegram, WhatsApp или Почте: Поделиться → Логи, и лог открывается здесь.

  1. Открой приложение Команды → +. Назови команду Логи.
  2. Нажми ⓘ внизу → включи Показывать в меню «Поделиться». Типы: оставь Файлы.
  3. Добавь действие Создать архив (Make Archive): на входе «Входные данные Быстрой команды», формат .gz.
  4. Добавь Кодировать Base64 (Base64 Encode), разрывы строк: Нет.
  5. Добавь Текст (Text): вставь адрес ниже и сразу за ним, без пробела, переменную из шага 4.
  6. Добавь Открыть URL (Open URLs) с этим текстом.

Лог передаётся внутри ссылки и разбирается на телефоне. На сервер он не уходит.
